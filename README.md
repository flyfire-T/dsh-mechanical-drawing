# 机械工程图工作流程

这是一个 DeepSeek Harness 插件包，提供 `mechanical-engineering-drawing` 技能，帮助整理机械设计、尺寸标注、装配说明和工程图检查流程。

## 功能

- 梳理设计依据、零件接口和装配顺序。
- 检查三视图、基准、孔槽定位、材料及技术要求。
- 提醒核验运动行程、干涉、标准件来源和制造可行性。
- 指导 PDF 工程图、原生装配模型及 STEP 文件的交付。

此插件提供方法说明，不自行建立 CAD 模型、执行计算或证明设计通过验证；具体工作仍取决于宿主可用的工具和用户授权。

## 安装

在支持插件包的 DeepSeek Harness 配置中，通过插件管理器安装本目录；安装方式和兼容性请以当前版本的官方文档为准。插件加载后，技能名为 `mechanical-engineering-drawing`。

## 数据和权限

插件代码通过宿主技能服务加载本包内的说明文件，不包含聊天读取、网络上传、数据采集或规避权限限制的功能。具体文件访问和联网由宿主工具及用户授权控制。

## 内容限制

工程图尺寸、配合、材料、采购件与标准适用性需根据具体项目核实；概念示意或局部检查不代表整机已通过验收。
